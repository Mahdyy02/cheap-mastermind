# Mastermind CP Solver

A solver for a 4-digit, per-position-feedback guessing game (like Mastermind, but
with Wordle-style per-slot feedback instead of aggregate peg counts). Given a
secret 4-digit code, the solver guesses it in **7 tries or fewer** across all
10,000 possible codes (`0000`–`9999`).

## How it works

Unlike classical Mastermind solvers (Knuth's minimax, entropy/information-gain
search), which maintain the full set of codes still consistent with all
feedback and reason about how each candidate guess would partition that set,
this solver never touches the 10,000-code space directly. Instead it tracks,
per digit, a small **constraint-propagation domain**:

- `in_pos[d]` — the positions digit `d` could still occupy
- `not_in_pos[d]` — the positions digit `d` is known **not** to occupy
- `correct` — positions already pinned to a specific digit

After the first few guesses (used to probe which digits are present at all),
each new guess is generated by taking the Cartesian product of the remaining
candidate digits for each unsolved position, then filtering that pool against
`not_in_pos`, `correct`, and previously-guessed codes.

This is closer to classic CSP forward-checking / arc-consistency than to a
Knuth-style search: it's cheap per guess (bounded by digit/position
combinatorics, independent of how large the remaining candidate space is),
at the cost of not being provably guess-optimal the way a full
minimax/entropy solver over the candidate set would be.

## Feedback rules

For each guessed digit, per position:
- `G` (green) — correct digit, correct position
- `Y` (yellow) — digit is present in the code, but not at this position
  (and not already fully accounted for by earlier greens/yellows for that digit)
- `R` (gray/red) — digit is absent from the code, or all its occurrences are
  already accounted for elsewhere in the guess

## Usage

```bash
python3 mastermind.py
```

Set `debug = True` in the script to print the guess-by-guess reasoning
(current `correct` array, digit domains, and remaining guess queue) for a
single test code. Set `candidates` to a list of codes (or all 10,000, or a
loop of random codes) to run a full sweep and report the failure count.

**Note:** the script's own guess-generation order currently depends on
Python's set/dict iteration order, which is affected by hash randomization
(`PYTHONHASHSEED`). For reproducible runs, pin the seed:

```bash
PYTHONHASHSEED=0 python3 mastermind.py
```

## Status / known limitations

- Solves all 10,000 codes in ≤7 guesses (verified empirically, with a fixed
  hash seed for reproducibility).
- Not guess-optimal — a Knuth-style minimax or entropy solver over the full
  candidate set could likely solve this variant in 4–5 guesses worst case,
  at higher computational cost per guess.
- Guess ordering (and therefore the exact number of guesses used on
  borderline codes) is currently sensitive to `PYTHONHASHSEED` unless pinned
  or the code is updated to iterate over `sorted()` digit sets instead of
  raw `set`/`dict` order.
